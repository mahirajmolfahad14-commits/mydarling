# Velvet Letter

A single-page, romantic poem reveal built with Next.js, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

- Replace the poem text in `app/page.tsx` (the `stanzas` array).
- Change the metadata in `app/layout.tsx`.
- Adjust colors, typography, ornaments and responsive styling in `app/globals.css`.

The sound control is intentionally a visual toggle only; no audio file is bundled. Add licensed ambient audio if you want real sound, and keep it opt-in.
